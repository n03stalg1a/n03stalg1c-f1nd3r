
# n03stalg1c f1nd3r

**n03stalg1c f1nd3r** is a simple command-line tool for finding and validating proxies from public sources. It supports multiple proxy types including HTTP, HTTPS, SOCKS4, and SOCKS5.

## Features
- Fetch proxies from multiple public sources.
- Validate proxies to ensure they are functional.
- Export validated proxies to a `.txt` file.

## Installation
1. Clone the repository:

```bash
git clone https://github.com/yourusername/n03stalg1c-f1nd3r.git
```

2. Navigate to the project directory:

```bash
cd n03stalg1c-f1nd3r
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

1. Run the script:

```bash
python proxy_finder.py
```

2. Select the type of proxies (HTTP, HTTPS, SOCKS4, or SOCKS5).
3. The script will fetch proxies from multiple sources and validate them.
4. Export the validated proxies to a `.txt` file.
